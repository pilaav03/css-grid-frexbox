# Forma Studio — CSS Grid i Flexbox

Praktični projekat uz diplomski rad **„Korišćenje CSS Grid i Flexbox tehnika za izradu modernih layouta“**.

Autor: Maid Pilav  
Broj indeksa: 239-R-240/22  
Studijski program: Računarstvo i informatika  
Predmet: Web dizajn

## Pokretanje

Nije potreban build proces niti dodatni paketi. Otvorite `index.html` u savremenom web pregledniku.

## Struktura

- `index.html` — semantička struktura stranice
- `css/style.css` — CSS Grid, Flexbox, responsive pravila i vizuelni identitet
- `js/main.js` — mobilni meni, tema, filter projekata, modal i validacija forme
- `screenshots/` — prikazi sekcija i tri ciljne širine
- `code-screenshots/` — prikazi reprezentativnih dijelova koda

## Tehnike

- CSS Grid za hero sekciju, usluge, projekte, poređenje tehnika i kontakt
- Flexbox za navigaciju, grupe dugmadi, proces, kartice tima i footer
- mobile-first prilagodbe za 390, 768 i 1440 piksela
- CSS custom properties, `clamp()`, `minmax()`, `gap` i pristupačna stanja fokusa
- JavaScript bez biblioteka

Sadržaj i naziv Forma Studio su demonstracijski i izrađeni isključivo za potrebe diplomskog rada.
